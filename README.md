# www-totemcraft

**Исходный код сайта [totemcraft.net](https://totemcraft.net)**

Форк [www-rpcs3](https://github.com/DAGINATSUKO/www-rpcs3) - адаптирован под проект TotemCraft.

---

## О проекте

Статический сайт ванильного Minecraft-сервера TotemCraft. Написан на чистом HTML/CSS/JS без фреймворков.

## Структура репозитория

| Папка / файл | Содержимое |
|---|---|
| `index.html` | Главная страница |
| `css/` | Стили сайта |
| `js/` | Скрипты |
| `img/` | Графика, иконки, мета-изображения |

## Связанные репозитории

- [TotemCraft-Docs](https://github.com/Dushelow/TotemCraft-Docs) — серверная документация, конфиги и скрипты
